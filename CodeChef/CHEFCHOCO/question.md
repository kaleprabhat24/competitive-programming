## Problem Statement

### Chef and Chocolates

Chef wants to gift CCC chocolates to Botswal on his birthday. However, he has only XXX chocolates with him.

The cost of 111 chocolate is YYY rupees.

Find the **minimum** money in rupees Chef needs to spend so that he can gift CCC chocolates to Botswal.

### Input Format

- First line will contain TTT, number of test cases. Then the test cases follow.

- Each test case contains of a single line of input, three integers C,X,C, X,C,X, and YYY.

### Output Format

For each test case, output in a single line answer, the **minimum** money in rupees Chef needs to spend.

### Constraints

- 1≤T≤1001 \leq T \leq 1001≤T≤100

- 1≤C≤1001 \leq C \leq 1001≤C≤100

- 0≤X≤C0 \leq X \leq C0≤X≤C

- 1≤Y≤1001 \leq Y \leq 1001≤Y≤100

### Explanation:

**Test Case 111:** Chef has to gift a total of 777 chocolates out of which he has 555 chocolates. Thus, Chef needs to buy 222 more chocolates, which costs him 101010 rupees.

**Test Case 222:** Chef has to gift a total of 101010 chocolates out of which he has 111 chocolate. Thus, Chef needs to buy 999 more chocolates, which costs him 999 rupees.
