## Problem Statement

### Ageing

Chef's current age is 202020 years, while Chefina's current age is 101010 years.

Determine Chefina's age when Chef will be XXX years old.

Note: Assume that Chef and Chefina were born on same day and same month (just different year).

### Input Format

- The first line of input will contain a single integer TTT, denoting the number of test cases.

- Each test case consists of a single integer XXX, the age of Chef.

### Output Format

For each test case, output Chefina's age when Chef will be XXX years old.

### Constraints

- 1≤T≤251 \leq T \leq 251≤T≤25

- 25≤X≤5025 \leq X \leq 5025≤X≤50

**Test case 111:** Chefina is 101010 years old when Chef is 202020 years old. Thus, when Chef would be 252525, Chefina would be 151515.

**Test case 222:** Chefina is 101010 years old when Chef is 202020 years old. Thus, when Chef would be 363636, Chefina would be 262626.

**Test case 333:** Chefina is 101010 years old when Chef is 202020 years old. Thus, when Chef would be 505050, Chefina would be 404040.

**Test case 444:** Chefina is 101010 years old when Chef is 202020 years old. Thus, when Chef would be 444444, Chefina would be 343434.
