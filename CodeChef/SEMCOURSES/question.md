## Problem Statement

### Chef and Chapters

This semester, Chef took XXX courses. Each course has YYY units and each unit has ZZZ chapters in it.

Find the total number of chapters Chef has to study this semester.

### Input Format

- The first line will contain TTT, the number of test cases. Then the test cases follow.

- Each test case consists of a single line of input, containing three space-separated integers X,Y,X, Y,X,Y, and ZZZ.

### Output Format

For each test case, output in a single line the total number of chapters Chef has to study this semester.

### Constraints

- 1≤T≤10001 \leq T \leq 10001≤T≤1000

- 1≤X,Y,Z≤10001 \leq X, Y, Z \leq 10001≤X,Y,Z≤1000

### Sample 1:

Input

Output

```
3
1 1 1
2 1 2
1 2 3
```

```
1
4
6
```

### Explanation:

**Test case 111:** There is only 111 course with 111 unit. The unit has 111 chapter. Thus, the total number of chapters is 111.

**Test case 222:** There are 222 courses with 111 unit each. Thus, there are 222 units. Each unit has 222 chapters. Thus, the total number of chapters is 444.

**Test case 333:** There is only 111 course with 222 units. Each unit has 333 chapters. Thus, the total number of chapters is 666.
