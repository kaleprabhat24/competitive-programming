## Problem Statement

### Counting Words

Harsh was recently gifted a book consisting of NNN pages. Each page contains exactly MMM words printed on it. As he was bored, he decided to count the number of words in the book.

Help Harsh find the total number of words in the book.

### Input Format

- The first line of input will contain a single integer TTT, denoting the number of test cases.

- Each test case consists of two space-separated integers on a single line, NNN and MMM — the number of pages and the number of words on each page, respectively.

### Output Format

For each test case, output on a new line, the total number of words in the book.

### Constraints

- 1≤T≤1001 \leq T \leq 1001≤T≤100

- 1≤N≤1001 \leq N \leq 1001≤N≤100

- 1≤M≤1001 \leq M \leq 1001≤M≤100

### Explanation:

**Test case 111:** The book consists of only 111 page, and each page has only 111 word. Hence, the total number of words is 111.

**Test case 222:** The book consists of 444 pages, and each page has 222 words. Hence, the total number of words is 2+2+2+2=82+2+2+2=82+2+2+2=8.

**Test case 333:** The book consists of 222 pages, and each page has 444 words. Hence, the total number of words is 4+4=84+4=84+4=8.
